AVI browser voice

Microphone capture and speaker playback for the local AVIP gateway. This page uses the existing 16 kHz pcm_s16le frames. When the gateway is running Gemini Live, it resamples provider audio to that profile before framing it. This page does not call Gemini, does not see the API key, and does not run an agent.

Permission. Start asks this page for the microphone. Samples leave the browser only as AVIP audio frames sent to this page’s own gateway. On the mock path the mirror sends those same bytes back. On the Live path the gateway sends provider audio instead. Nothing is written to disk.

Secure context. Browsers expose the microphone only on HTTPS, or on http://localhost and http://127.0.0.1. Opening the file directly (file://) or from another host will not prompt. This development gateway also accepts only http://127.0.0.1:8000 and http://localhost:8000.

Headphones. The mock path plays your microphone back through the speakers, and Live playback can feed the mic. Headphones keep that loop from building.

Manual checks

  • Deny the microphone prompt. The page reports permission denied and does not keep a capture track. No session is opened.
  • Allow the microphone, then press Stop playback. Uplink frames keep increasing, the speaker goes quiet, and the session stays open. That button does not send a cancel.
  • Unplug the headset or stop the browser’s microphone. The page reports that the track ended, capture stops, and the session stays open until you end it or the socket closes.
  • Stop the gateway. The page reports the disconnect and releases the microphone.
  • Start the gateway with neither Live credentials nor AVIP_MOCK_MEDIA=1. The page reports that audio was not negotiated and releases the microphone.

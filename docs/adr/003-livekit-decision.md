# ADR-003: LiveKit and Pipecat
Status: accepted.

Neither is a mandatory v0.1 dependency. Reconsider when WebRTC, NAT traversal,
multi-device sessions, media routing or scaling justify the additional machinery.
AVI remains an interaction layer and does not attempt to replace these projects.
